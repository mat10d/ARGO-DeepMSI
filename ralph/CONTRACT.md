# ARGO-DeepMSI autorun CONTRACT (invariants — violating any = revert the iteration)

## Regime
1. **NO NEW TRAINING DATA.** Only slides in `results/data/cohort_clean.csv` (rows with
   `in_clean_set=1`). Fitting a small head on our ~200 patients is allowed. Loading TCGA /
   PAIP / any external labelled slide set is forbidden. Frozen pretrained FM weights
   (UNI/CONCH/Virchow/TITAN/PRISM) are feature extractors, not external training — allowed.
   Enforced by `tests/test_no_external_data.py`.

## Repo shape (never invent new top-level dirs)
- Scorer:  `argo_deepmsi/scorers/<name>.py`  (subclass `Scorer`, call `register()`)
- Eval:    `argo_deepmsi/eval/`  (metrics.py, screening.py, cohort.py, qc_comparison.py, plotting.py)
- Compute wrappers: `scripts/<name>.sh`
- Canonical data:   `results/data/`
- Per-scorer output: `results/scorers/<name>/` (slide_scores.csv + metrics.json)
- Leaderboard: `results/comparison/` (regenerated by qc_comparison, never hand-edited)
- Harness: `ralph/`   Tests: `tests/`   Writeups: `docs/experiments/<id>.md`

## Per-task rules
2. One scorer = one file + one `register()` + one contract test + one `metrics.json`
   carrying the FULL metric block (see §Metric block). No partial landings.
3. Every result scored on `cohort_clean.csv`. Report **sensitivity, specificity@sens{0.90,0.95},
   NPV, AUROC, AUPRC** — overall, `by_site`, `by_bagsize`. AUROC alone is NOT a result.
4. Never edit another scorer's file to make yours win. Scorers are append-only siblings.
5. Leaderboard regenerated via `python -m argo_deepmsi.eval.qc_comparison`, never hand-edited.
6. Commit per completed task (conventional commits: `scorer:`/`eval:`/`qc:`/`docs:`),
   message references the BACKLOG id.
7. No new dependency without adding it to `pyproject.toml` + a JOURNAL note.
8. Determinism: `seed=42`, `StratifiedGroupKFold(patient_id)`, 5 folds.

## Metric block (every results/scorers/<name>/metrics.json)
```
sensitivity, spec_at_sens90, spec_at_sens95, npv_at_sens95,
auroc, auprc, operating_threshold,
by_site: {<site>: {n, prevalence, spec_at_sens95, auroc}},
by_bagsize: {<bucket>: {n, auroc}}
```

## GPU budget
- **Hard cap: 3 concurrent SLURM GPU jobs.** The loop must not submit a 4th while 3 are
  running/pending (`ralph/gpu_gate.sh` blocks until a slot frees). Never bypass the gate.

## Stop / halt
- **LOOP-COMPLETE** when: all backlog `done` and `verify.sh` green, OR champion clears
  **specificity >= 0.47 @ sensitivity >= 0.96** on the clean cohort AND the fairness gate (T3)
  shows no disqualifying per-site outlier.
- **HALT for human** (not complete) when: working tree dirty after an iteration, a task hits
  `blocked` twice, or `verify.sh` cannot pass without weakening a gate. NEVER weaken a gate.
